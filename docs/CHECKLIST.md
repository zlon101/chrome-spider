# 安装检查清单 ✓

在开始使用扩展之前，请按照此清单确保所有步骤都已完成：

## □ 第 1 步：生成图标文件

**这是必须完成的步骤！**没有图标文件，Chrome 无法安装扩展。

### 方法 1：使用 generate-icons.html（推荐）

- [ ] 在浏览器中打开 `generate-icons.html`
- [ ] 点击"下载所有图标"按钮
- [ ] 将下载的三个文件移动到 `icons/` 文件夹：
  - [ ] icon16.png
  - [ ] icon48.png
  - [ ] icon128.png

### 方法 2：使用在线工具

- [ ] 访问 https://www.favicon-generator.org/
- [ ] 上传 `icons/icon.svg` 文件
- [ ] 下载生成的图标
- [ ] 重命名并放入 `icons/` 文件夹

### ✅ 验证图标是否正确

运行以下命令检查：

```bash
ls -la /Users/admin/work/chrome-spider/icons/
```

应该看到：
```
icon16.png
icon48.png
icon128.png
icon.svg
ICON_GUIDE.md
```

---

## □ 第 2 步：安装 Chrome 扩展

- [ ] 打开 Chrome 浏览器
- [ ] 在地址栏输入：`chrome://extensions/`
- [ ] 打开右上角的"开发者模式"开关
- [ ] 点击"加载已解压的扩展程序"
- [ ] 选择文件夹：`/Users/admin/work/chrome-spider`
- [ ] 确认扩展图标出现在浏览器工具栏

### ⚠️ 如果安装失败

**错误："Manifest file is missing or unreadable"**
- 检查 `manifest.json` 文件是否存在
- 确保文件没有语法错误

**错误："Could not load icon"**
- 返回第 1 步，确保图标文件存在
- 检查文件名是否正确（区分大小写）

## 🆘 需要帮助？

如果遇到问题：

1. **查看文档**
   - README.md 的"常见问题"章节
   - QUICK_START.md 的"常见问题"章节

2. **检查控制台**
   - 按 F12 打开开发者工具
   - 查看 Console 标签页的错误信息

3. **验证选择器**
   - 在控制台测试：`document.querySelector('你的选择器')`
   - 确保返回了正确的元素

4. **重新安装扩展**
   - 在 chrome://extensions/ 中移除扩展
   - 重新加载扩展程序
