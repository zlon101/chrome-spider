# 更新日志

## v1.2.0 (2026-01-14) - 列表详情页抓取

### 🎉 重大更新

#### 新增功能

**列表详情页自动抓取**
- ✨ 支持在抓取列表的同时自动打开详情页抓取深度数据
- ✨ 新标签页模式：在后台自动打开详情页，不干扰当前浏览
- ✨ 智能数据合并：自动合并列表字段和详情字段
- ✨ 灵活配置：可选择只抓列表、只抓详情、或两者都抓
- ✨ 详情进度显示：实时显示当前详情页抓取进度
- ✨ 错误处理：详情页抓取失败自动重试，记录错误信息

#### 配置扩展

**新增配置项**
- `list_fields`: 列表页字段配置（可选）
- `detail_config`: 详情页配置对象（可选）
  - `link_selector`: 详情页链接选择器（必需）
  - `wait_time`: 页面加载等待时间（可选，默认 2000ms）
  - `detail_fields`: 详情页字段配置（必需）

**配置示例**:
```json
{
  "container": ".product-item",
  "list_fields": {
    "商品名": ".title",
    "价格": ".price"
  },
  "detail_config": {
    "link_selector": "a.detail@href",
    "wait_time": 2000,
    "detail_fields": {
      "详细描述": ".description",
      "规格": ".specs"
    }
  }
}
```

#### 技术实现

- 🔧 扩展 `content.js`：添加 `getDetailLinks` 和 `scrapeDetailFields` 功能
- 🔧 扩展 `background.js`：添加标签页管理和详情页抓取协调
- 🔧 更新 `popup.js`：添加详情抓取逻辑和进度显示
- 🔧 更新 `popup.html`：添加详情进度显示UI
- 🔧 新增权限：`tabs` 用于标签页管理

#### 文档更新

- 📚 新增 `docs/LIST_DETAIL_GUIDE.md` - 列表详情页抓取完全指南
- 📚 新增 `docs/LIST_DETAIL_FEATURE.md` - 功能更新说明
- 📚 新增 `tests/test-list-detail-page.html` - 列表详情页测试页面

#### 测试页面

- 🧪 创建完整的列表+详情测试页面
- 🧪 包含 3 页列表，每页 5 个商品
- 🧪 每个商品都有对应的详情页
- 🧪 提供完整的测试配置和预期结果

### 🐛 问题修复

- 修复列表抓取时的字段兼容性问题
- 优化错误提示信息

### 📈 性能优化

- 自动重试机制：详情页抓取失败自动重试 3 次
- 并发控制：防止同时打开过多标签页
- 内存优化：详情页抓取完成立即关闭标签页

### ⚠️ 注意事项

1. **性能考虑**：详情页抓取会占用较多内存和网络资源
2. **等待时间**：根据网站实际情况调整 `wait_time`
3. **数据量**：建议单次抓取不超过 50 项详情页
4. **网站规则**：尊重网站的 robots.txt 和服务条款
