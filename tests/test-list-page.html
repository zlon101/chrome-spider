测试配置（列表页面）

在扩展中使用以下配置来抓取此列表页面的数据：

{
  "container": ".article-item",
  "next_button": ".next-page",
  "max_page": 3,
  "field": {
    "标题": ".article-title",
    "摘要": ".article-summary",
    "作者": ".article-author",
    "日期": ".article-date",
    "链接": ".article-link@href"
  }
}

测试步骤：

  1. 确保当前在第 1 页
  2. 打开 Chrome 扩展
  3. 选择"列表页面"模式
  4. 粘贴上面的配置
  5. 点击"开始抓取列表"
  6. 观察扩展自动翻页并抓取数据
