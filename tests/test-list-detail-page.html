测试配置（列表+详情页）

在扩展中使用以下配置来抓取列表和详情页数据：

{
  "container": ".product-item",
  "next_button": ".next-page",
  "max_page": 2,
  "list_fields": {
    "商品名称": ".product-title",
    "价格": ".product-price",
    "简介": ".product-summary"
  },
  "detail_config": {
    "link_selector": ".product-link@href",
    "wait_time": 1500,
    "detail_fields": {
      "详细描述": ".detail-content",
      "规格参数": ".detail-specs",
      "作者": ".detail-author"
    }
  }
}

测试步骤：

  1. 确保当前在第 1 页
  2. 打开 Chrome 扩展
  3. 选择"列表页面"模式
  4. 粘贴上面的配置
  5. 点击"开始抓取列表"
  6. 观察扩展自动抓取列表和详情页

预期结果：

应该抓取到 2 页共 10 条数据，每条包含列表字段和详情字段的合并数据
